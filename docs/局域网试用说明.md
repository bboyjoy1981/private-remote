# Private Remote 局域网试用版

这是两台自有 Windows 电脑的试用版本。当前使用 JPEG 基础画面通路，尚未完成两台实体电脑的显示、输入和流畅度实测。

## 启动

1. 两台电脑连接同一局域网。把整个压缩包解压到各自电脑，不能只复制一个 exe。
2. 双击 `启动软件.cmd`。包内含本地 .NET 运行时，无需在另一台电脑安装开发 SDK。
3. 不要以管理员身份运行日常远程控制。锁屏、登录界面和 UAC 安全桌面不支持控制。

## 第一次配对（五分钟内完成）

1. 电脑 A 点击“导出邀请文件”，通过你信任的渠道交给 B。邀请文件包含一次性配对秘密，不能公开分享。
2. B 点击“导入配对文件”，核对 A 的完整设备 ID，选择屏幕控制、文件传输权限，批准后保存申请文件并交回 A。
3. A 导入申请文件，核对 B 的设备 ID和权限，在本机批准，保存回执并交回 B。
4. B 导入回执。双方列表均出现另一台电脑后，完成双向配对。

双方程序须保持打开；过期、程序重启或申请丢失时，重新生成邀请并重做。保存申请或回执时取消了对话框，可用“重新导出申请/回执”。私钥不会写入配对文件。

## 建立局域网连接

1. 在 A 的设备列表选中 B。
2. 在右侧填写 A 的局域网 IPv4 地址，例如 `192.168.1.10`。留空时软件会选择一个地址，多网卡/VPN 环境需自行核对。
3. A 点击“本机启动信令并导出另一台配置”，保存生成的连接配置，交给 B。该文件只供 B 使用，包含连接令牌，请勿公开分享。
4. B 点击“导入本机连接配置”。软件校验配置是否由已经配对的 A 签名，并固定核对 WSS 服务证书。
5. 两端服务在线后，选中另一台设备并连接。点击“打开远程桌面”或“文件传输”。

A 的信令服务使用 TCP 5443。Windows 防火墙若提示，选择允许专用网络。不要在路由器上做公网端口转发。只有双方已配对身份和令牌能通过服务认证，远程内容另由 WebRTC 加密。

若 Windows 未弹出防火墙提示，可在 A 的“高级安全 Windows Defender 防火墙”中，为本目录 `PrivateRemote.Client.exe` 添加入站 TCP 5443、专用配置文件、远程地址“本地子网”的允许规则。无需开放公用网络。

首次成功导入的连接设置保存在当前 Windows 用户的 DPAPI 加密文件中。之后程序启动会尝试恢复信令服务/连接；这不等同于程序已配置开机启动。A 的地址变化后需重新导出配置。服务证书有效期一年，到期后需更新证书与两端配置，当前尚无自动轮换流程。

## 操作与传文件

- 关闭与输入修复版：远程窗口新增“停止投屏（保持在线）”按钮；修正关闭回调中再次同步 Close 导致的进程闪退。主窗口正常收起托盘，单独“退出软件”结束服务。
- 中文输入默认使用“兼容粘贴”：会把发送的文字设置为**远端剪贴板**并向目标窗口发送 Ctrl+V。先点远端目标输入框，再在顶部输入文字并发送。取消该选项会改用 Unicode 输入；部分目标应用不接受该方式。发送内容保留在顶部输入框，收到远端 Windows 的反馈后再自行清空；反馈表示系统接收输入，不代表目标应用已保存文字。
- 连接前先检测另一台的信令在线状态。首次更新时，两边都彻底退出旧版（含托盘），运行修复版；只需其中一端点“连接选中的设备”，另一端自动接收。单实例限制会防止后续重复启动同一用户的新版本。

- 中文输入：先在远端画面中点中聊天框、记事本等目标输入位置，再到远程窗口顶部“中文/文字”输入框中使用本机输入法选词，点击“发送文字”。每次最多 128 个 UTF-16 字符，支持中文及合法的 Emoji；该入口只发送选好的文字，不同步剪贴板。回车、退格等操作仍在远端画面中通过按键进行。两台电脑都需要更新，旧版没有文字输入消息支持。

- 主窗口点击 × 或最小化会收起到右下角托盘，保持后台连接。双击托盘图标可恢复窗口；右键菜单或主窗口底部的“退出软件”才会断开并退出。关闭远程查看窗口只停止查看。
- 远程窗口的“适应窗口”显示完整画面；“原始大小 1:1”按像素显示，窗口不够大时用滚动条移动；F11 或“全屏”可扩大操作区域。
- 画质下拉框提供“省流（720p）”“均衡（900p）”“清晰（原画≤4K）”。清晰档更占带宽；目标屏幕本身低于上限时不会凭空增加分辨率。关闭安全的鼠标键盘控制后，可以使用鼠标滚轮滚动画面区域。
- 本次新增画质控制消息，两台电脑都需要换成这一版。更新前请通过“退出软件”彻底退出旧程序；旧版没有托盘菜单时，先正常关闭主窗口。

- 鼠标在实际画面区域内操作；画面两侧的黑边不发送位置。
- F12、取消勾选控制或切换离开窗口会释放远端按键并暂停输入，恢复时重新勾选。
- 关闭查看窗口停止共享；不能及时送达停止消息时，软件关闭该加密会话。
- 文件接收必须选择保存位置，不覆盖已有文件；接收完成后核对 SHA-256，再把临时文件提交为正式文件。
- 关闭文件窗口或点击取消会中止传输并清理未完成文件。
- 撤销设备后不能再连接；需要双方重新批准配对。若同时撤销服务凭据，重新导出连接配置。

## 当前限制

连接诊断版修正候选信息早于 SDP 的发送顺序，并在远端描述应用前暂存已验证的候选（每方向最多 64 条）。双方同时点击连接时，以设备身份顺序选择一方发起，避免双方都等待答案。仍失败时，在两台主窗口点击“复制连接诊断”，保留双方内容；其中包含 UTC 时间、SDP/候选计数、通道状态和局域网候选地址，不含令牌、私钥或完整 SDP。

- 仅供局域网联调，尚未提供公网 TURN 穿透和正式生产部署。
- JPEG 默认均衡档将完整虚拟桌面缩放到最多 1600×900，清晰档最高 3840×2160；高帧率 H.264 尚未完成。多显示器会合并缩放。
- 键盘仅转发查看窗口收到的按键，不拦截 Windows 系统快捷键，不生成 Ctrl+Alt+Del 安全注意序列。
- 程序未进行代码签名或建立自动更新渠道，也尚未做真实双机体验验收。
- 本机检查已验证配对文件、固定证书 WSS、原生加密会话、合成画面/输入及双向文件传输。内嵌局域网服务的保护状态重启探针仍需在正常桌面上下文完成。

遇到问题请保留界面底部的错误文字；不要发送包含令牌的连接配置或一次性邀请文件。
