# 画质优化补丁

2026-10-16。

两台电脑点击“退出软件”，把补丁文件覆盖到各自原来包含“启动软件.cmd”和“runtime”的软件目录，再启动。无需重新配对、导入连接配置或调整 Tailscale。

此更新保留时钟偏差修复，主窗口仍显示“信令追踪版”。投屏窗口出现“帧/秒”和“Mbps”即可识别本次更新。

## 改动

- 清晰档 JPEG 编码质量由 90 提高到 95，最大分辨率仍受远端实际屏幕与 3840×2160 限制，不放大小屏幕。
- 桌面缩小捕获使用 HALFTONE 采样；是否明显改善取决于文字、比例与屏幕内容。
- 在一次设备连接中记住查看端选择的画质；重新打开投屏会再次发送所选档位，避免界面与远端实际档位不一致。
- 显示本机实际显示帧率及收到的 JPEG 画面数据速率。Mbps 不含协议开销，不是网络测速或可用带宽。统计在新画面到达时更新，不能用于判断静止或断流时的瞬时状态。

## 怎么选

外网先用“均衡（900p）”；阅读小字可选“清晰（原画≤4K）”，并切“原始大小 1:1”。清晰档会增加流量，网络差时可切省流。画面仍为 JPEG 基础模式，未加入 H.264 或硬件编码。

两台均更新后，互相查看才能使用更新后的捕获效果。已编译通过，尚未实测本次画质效果、帧率和外网流畅度。

Tailscale 管理网页可以关闭；两台 Tailscale 保持后台已连接，Private Remote 保持运行。A 需要已登录、未锁屏且不休眠。
