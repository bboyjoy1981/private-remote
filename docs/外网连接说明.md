# A 在家、B 笔记本在外：连接步骤

## 1. 两台安装并登录 Tailscale

官方 Windows 下载：https://tailscale.com/download/windows

两台登录同一个个人账户。个人非商业用途可使用免费 Personal 方案，以官方当时政策为准：https://tailscale.com/pricing

登录由使用者本人完成。两台应在同一虚拟网络中，且 Tailscale 均显示已连接。A 获得形如 100.x.x.x 的 Tailscale IPv4 地址。

Tailscale 是网络连接工具，远程画面和操作继续使用 Private Remote。

## 2. A 导出使用虚拟地址的连接配置

保留目前已修复时钟偏差、已经成功连接的 Private Remote 版本。

1. 先停止当前投屏或断开设备会话。
2. A 在已配对列表选择 B。
3. A 右侧“本机局域网 IPv4”填 A 的 Tailscale IPv4（100.x.x.x），不要填 B 的地址。
4. 点击“本机启动信令并导出另一台配置”，保存新连接配置文件交给 B。
5. A 本机信令地址继续使用 wss://127.0.0.1:5443/signal。

此步骤沿用现有配对，不需要再次交换邀请、申请或回执。配置文件包含连接令牌，只交给自己的 B，不要贴到聊天或公开上传。

## 3. B 导入后连接

1. B 点击“导入本机连接配置”，选择 A 刚生成的文件。
2. B 的信令地址应为 wss://A的Tailscale地址:5443/signal。
3. 等两台信令在线，B 选择 A，点击连接，再打开远程桌面。
4. 要确认外网可用，B 最后需换到手机热点或其他外部网络再连接一次。同一家庭 Wi-Fi 下连接成功不能证明外网已经可用。

## 使用条件和画质

A 要保持开机、已登录 Windows、屏幕未锁定且不休眠，Private Remote 和 Tailscale 保持运行。当前 Private Remote 不支持 Windows 登录界面、锁屏或 UAC 安全桌面；Tailscale 在线不代表能操作这些界面。

先使用 720p 或 900p 档位；文字不清楚时再提高分辨率。当前仍是 JPEG 画面传输，不是 H.264 硬件编码。外网清晰度和延迟需结合家庭上传、B 网络以及直连或中继情况判断。

Tailscale 会尝试直连，无法直连时可经中继：https://tailscale.com/docs/reference/connection-types
