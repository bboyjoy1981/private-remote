# 时钟偏差修复补丁

2026-10-16。

本次只需更新运行信令服务器的 A 电脑。退出 A 的软件，把 PrivateRemote.Relay.dll 覆盖到原软件目录，然后启动原来的“启动软件.cmd”。B 保持运行即可；等待其信令重新在线后，由 A 发起连接。无需重新配对或导入配置。标题仍为“信令追踪版”。

原因：B 在其时间 06:31:39.482 发出 answer，A 在其时间 06:31:38.202 收到。Relay AccessPolicy 额外要求发送时间不能晚于服务器时间，与 SignalingProtocol 已有的双向一分钟容差不一致，导致稍快的 B 被拒绝。移除这项单向额外限制，继续使用现有双向一分钟窗口。

签名、设备授权、重复 nonce 检查和两分钟 nonce 缓存保留。超过一分钟的时间差仍会拒绝。

此补丁已编译并核对打包文件；尚未在用户两台实机上确认连接结果。
