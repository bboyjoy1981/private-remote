# 握手修复补丁

本补丁用于已经解压的 Private Remote 局域网试用版，不能单独运行。

1. 两台电脑都先使用主窗口底部“退出软件”，或托盘右键“退出软件”。点击 × 只是收起窗口。
2. 把补丁压缩包解压到原来包含 `启动软件.cmd` 和 `runtime` 文件夹的那一级，选择替换同名文件。不要把补丁单独解压后运行。
3. 两边重新双击原目录的 `启动软件.cmd`，标题应显示“握手修复与诊断版”。配对和连接配置保留。
4. 只需一边点击“连接选中的设备”。此次也处理了两边同时发起连接时的冲突。

若仍失败，请在两台主窗口各点“复制连接诊断”，把两份内容发回。包含 UTC 时间、描述/候选交换计数、通道状态和局域网候选地址；不包含服务令牌、私钥和完整 SDP。

本机已检查到 Windows 防火墙所有配置均关闭，没有修改防火墙。另一台电脑的防火墙状态尚不清楚。修改候选信息时序和并发连接逻辑不等于已证明此次用户网络故障的唯一原因；这版需确认实际双机结果。
